# Support

## Getting help

Use the repository's GitHub Issues page for reproducible questions and defects: <https://github.com/Brajesh31/Book-Recommender/issues>. Before opening an issue, search existing reports and check the installation and troubleshooting guides in `docs/`.

Include the operating system, Python version, installation steps, command used to start the app, the route or notebook cell involved, and the complete relevant error message. Explain what you expected and what happened. Remove names, email addresses, user IDs, private ratings, credentials, and other personal or confidential information from logs and examples. Do not upload private datasets or model artifacts.

## Bug reports and feature requests

For a bug, provide the smallest set of steps and sample input that reproduces it. For a feature request, describe the user problem and the intended result. Avoid placing secrets or personal data in public issues.

## Security reports

Do not report a suspected vulnerability in a public issue. Follow the private reporting instructions in `SECURITY.md`. This repository does not publish a response-time guarantee; include a safe way to reproduce the issue and allow time for review.

## Project scope

This is a small educational Flask recommendation demo. It has no published service-level commitment, paid support, or guaranteed maintenance schedule. The repository owner may prioritize reports at their discretion.
